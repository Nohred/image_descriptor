# Documentación

La documentación se compila desde esta carpeta con:

```bash
latexmk -pdf main.tex
```

La bitácora independiente se compila con:

```bash
latexmk -pdf bitacora.tex
```

Las figuras propias del proyecto deben colocarse en `figuras/`.
Los resultados todavía no medidos se marcan como `PENDIENTE`.
